# UI-автотесты для practice-automation.com

Проект UI-автотестов на Python для страниц https://practice-automation.com/: календарь, модальные окна, рекламные окна и форма.

## Стек

- Python 3.12+
- Selenium 4 (драйверы подтягивает Selenium Manager)
- Pytest
- Allure (allure-pytest)
- Паттерн Page Object Model

## Структура

```
.
├── conftest.py            фикстуры, запуск браузера, скриншоты при ошибках
├── pytest.ini
├── requirements.txt
├── pages/
│   ├── base_page.py       общие методы и ожидания
│   ├── popup.py           общий компонент всплывающего окна
│   ├── calendar_page.py
│   ├── modals_page.py
│   ├── ads_page.py
│   └── form_fields_page.py
└── tests/
    ├── test_calendar.py
    ├── test_modals.py
    ├── test_ads.py
    └── test_form_fields.py
```

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

pytest                           # Chrome
pytest --browser=firefox         # Firefox
pytest --headless                # без окна браузера
pytest -m positive               # только позитивные
pytest -m negative               # только негативные
```

Для отчёта нужен установленный Allure Commandline:

```bash
allure serve allure-results
```

Результаты складываются в `allure-results/`. При падении теста к нему прикрепляется скриншот.

Перед запуском отключите блокировщики рекламы в браузере: без этого на сайте не появляются модальные окна.

## Тестовые сценарии

### Календарь (/calendars/)

Позитивные

| № | Сценарий | Ожидаемый результат |
|---|----------|---------------------|
| CAL-P1 | Открыть страницу | Заголовок «Calendars» |
| CAL-P2 | Посмотреть подсказку в поле даты | Указан формат YYYY-MM-DD |
| CAL-P3 | Кликнуть по полю даты | Открывается календарь |
| CAL-P4 | Открыть календарь | Сегодняшний день подсвечен |
| CAL-P5 | Выбрать через календарь 2024-03-15, 2024-02-29 (високосный день) и дату через 90 дней | В поле записана выбранная дата в формате YYYY-MM-DD |
| CAL-P6 | Выбрать дату | Календарь закрывается |
| CAL-P7 | Переключить месяц вперёд и назад | Месяц меняется ровно на один, затем возвращается |
| CAL-P8 | Ввести дату 2025-12-31 вручную | Значение сохраняется в поле |
| CAL-P9 | Ввести дату вручную и открыть календарь | Календарь показывает декабрь 2025 |
| CAL-P10 | Выбрать дату и нажать Submit | Появляется подтверждение отправки |

Негативные

| № | Сценарий | Ожидаемый результат |
|---|----------|---------------------|
| CAL-N1 | Открыть страницу, не трогая поле | Календарь скрыт |
| CAL-N2 | Открыть страницу | Поле даты пустое |
| CAL-N3 | Открыть календарь и кликнуть вне его | Календарь закрыт, дата не выбрана |
| CAL-N4 | Выбрать дату, не нажимая Submit | Подтверждение не показывается |

### Модальные окна (/modals/)

Позитивные

| № | Сценарий | Ожидаемый результат |
|---|----------|---------------------|
| MOD-P1 | Открыть страницу | Заголовок «Modals» |
| MOD-P2 | Посмотреть кнопки | Есть Simple Modal и Form Modal |
| MOD-P3 | Нажать Simple Modal | Открывается простое окно |
| MOD-P4 | Прочитать текст простого окна | Текст содержит «simple modal» |
| MOD-P5 | Закрыть простое окно по × | Окно закрывается |
| MOD-P6 | Нажать Form Modal | Открывается окно с формой |
| MOD-P7 | Посмотреть поля формы | Есть Name, Email, Message и Submit |
| MOD-P8 | Закрыть окно с формой по × | Окно закрывается |
| MOD-P9 | Заполнить все поля и нажать Submit | Появляется подтверждение |
| MOD-P10 | Заполнить только Name и нажать Submit | Появляется подтверждение |

Негативные

| № | Сценарий | Ожидаемый результат |
|---|----------|---------------------|
| MOD-N1 | Открыть страницу | Оба окна скрыты |
| MOD-N2 | Открыть и закрыть простое окно | Оно остаётся закрытым, форма не открывается |
| MOD-N3 | Нажать Submit с пустой формой | Подтверждения нет, окно остаётся открытым |
| MOD-N4 | Заполнить Email и Message без Name | Форма не отправляется |
| MOD-N5 | Ввести некорректный email и нажать Submit | Поле невалидно, форма не отправляется |

### Рекламные окна (/ads/)

Позитивные

| № | Сценарий | Ожидаемый результат |
|---|----------|---------------------|
| ADS-P1 | Открыть страницу | Заголовок «Ads» |
| ADS-P2 | Посмотреть навигацию | Есть ссылка Home |

| ADS-P7 | Закрыть рекламу по × | Окно закрывается |
| ADS-P8 | Закрыть рекламу и прочитать страницу | Основной текст доступен |

Негативные

| № | Сценарий | Ожидаемый результат |
|---|----------|---------------------|

### Форма (/form-fields/)

Позитивные

| № | Сценарий | Ожидаемый результат |
|---|----------|---------------------|
| FRM-P1 | Открыть страницу | Заголовок «Form Fields» |
| FRM-P2 | Получить список из раздела Automation tools | В списке есть Selenium |
| FRM-P3 | Получить список Automation tools средствами Selenium и записать его в Message через запятую | В Message: Selenium, Playwright, Cypress, Appium, Katalon Studio |
| FRM-P4 | Выбрать напиток, цвет и ответ на вопрос об автоматизации | Выбранные значения отмечены |
| FRM-P5 | Заполнить все поля (Message со списком инструментов) и нажать Submit | Появляется alert «Message received!» |

Негативные

| № | Сценарий | Ожидаемый результат |
|---|----------|---------------------|
| FRM-N1 | Нажать Submit с пустой формой | Alert об успешной отправке не появляется |
| FRM-N2 | Заполнить только Message и нажать Submit | Alert об успешной отправке не появляется |
| FRM-N3 | Ввести некорректный email | Поле помечено как невалидное |

## Allure-отчёт

- Тесты сгруппированы по страницам (feature), у каждого есть понятное название и уровень важности.
- Действия в page object оформлены как шаги (`allure.step`).
- При падении теста автоматически прикрепляется скриншот.
